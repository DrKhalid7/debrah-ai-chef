# 🍳 دبْرة (Debrah) - Smart AI Clinical Chef

**دبْرة** هو تطبيق ويب تفاعلي (MVP) يعمل كمساعد تغذية سريرية وشيف ذكي. يهدف التطبيق إلى تحويل المكونات المتوفرة في مطبخ المستخدم إلى وصفات دقيقة، مع تطبيق **قيود طبية صارمة** بناءً على الحالة الصحية والنظام الغذائي للمستخدم.

---

## 🌟 الميزات الرئيسية (Features)

* 🛡️ **حارس البوابة الطبية (Medical Gatekeeper):** خوارزمية ذكية تمنع توليد وصفات تتعارض مع الأمراض المزمنة (مثل السكري، الضغط، الكوليسترول، حساسية اللاكتوز والجلوتين).
* 🔄 **اقتراح البدائل الذكية (Smart Alternatives):** إذا طلب المستخدم مكوناً مضراً بحالته، يرفض التطبيق إكمال الوصفة ويقترح بدائل صحية مدعومة بتفسير طبي.
* 📊 **التحليل الغذائي (Nutritional Facts):** حساب دقيق للسعرات الحرارية والمغذيات الكبرى لكل وجبة بناءً على الكميات المدخلة.
* 💾 **الذاكرة المخبئية (Local Database):** نظام حفظ واسترجاع للوصفات المفضلة باستخدام قاعدة بيانات محلية، مما يقلل استهلاك الـ API ويسرع تجربة المستخدم.
* ⚙️ **التجاوز المسؤول (Override Mode):** منح المستخدم حرية تجاوز التحذيرات الطبية وتوليد الوصفة على مسؤوليته، مع إرفاق إخلاء مسؤولية وتوعية طبية شديدة اللهجة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **لغة البرمجة الأساسية:** Python 3
* **واجهة المستخدم (Frontend):** Streamlit
* **محرك الذكاء الاصطناعي (AI Engine):** Google Gemini API (gemini-3.8-flash) عبر JSON Schema
* **قاعدة البيانات (Database):** SQLite3
* **المرونة (Resilience):** Exponential Backoff algorithm للتعامل مع ضغط سيرفرات الذكاء الاصطناعي (HTTP 503/429).

---

## 🧠 الرؤية التقنية والطبية (Why Debrah?)

تم بناء هذا التطبيق كإثبات مفهوم (Proof of Concept) لدمج **المعلوماتية الصحية (Health Informatics)** مع **تطبيقات الذكاء الاصطناعي التوليدي (GenAI)**. يعكس المشروع القدرة على:
1. هندسة الأوامر المتقدمة (Advanced Prompt Engineering) لإجبار النماذج اللغوية على الالتزام بقيود سريرية دقيقة (Valid JSON Output).
2. بناء منتج رقمي متكامل (MVP) جاهز للتحول لاحقاً إلى تطبيق هواتف ذكية (iOS/Android).
